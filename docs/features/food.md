# Еда (углеводы)

- Запись приёма пищи с количеством углеводов
- Ввод в граммах (0.1–500г) или в хлебных единицах (ХЕ) — с автоконвертацией по настройке пользователя
- Опциональное примечание к записи
- Время приёма: пресеты (сейчас, −15 мин, −30 мин, −1 час) или ручной ввод (`HH:MM` / `DD.MM HH:MM` / `DD.MM.YYYY HH:MM`)
