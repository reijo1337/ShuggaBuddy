# Калькулятор болюса

## UI (delivery)

- Встроен в флоу записи инсулина: при выборе болюса — «Ввести дозу» или «Калькулятор»
- Предложение последнего показания глюкозы (если < 30 мин) или ручной ввод
- Краткий результат + кнопка «Подробнее» с пошаговым объяснением
- Кнопка «Записать» сохраняет как инъекцию с пометкой source=calculator

## Бизнес-логика (usecase)

- Расчёт рекомендуемой дозы на основе текущей глюкозы и планируемых углеводов
- **ICR** (insulin-to-carb ratio): из исторических цепочек еда→болюс→глюкоза за 14 дней; только цепочки с постпрандиальной глюкозой в целевом диапазоне; минимум 5 цепочек
- **ISF** (insulin sensitivity factor): из коррекционных болюсов без еды за 14 дней; минимум 5 цепочек
- **IOB** (insulin on board): линейная модель затухания, учитывает все болюсные инъекции в пределах DIA
- DIA определяется по `BolusInsulinCatalog` (Fiasp, NovoRapid, Humalog, Apidra, Росинсулин Аспарт, Actrapid, Humulin R, Lyumjev)
- Итоговая доза = foodDose + correctionDose − IOB (floor 0)
- Настройка болюсного препарата в профиле обязательна
- Минимум 5 цепочек за 14 дней для выдачи рекомендации, иначе — отказ
